# HOMEONE – All-in-One Home Services

Welcome to the **HOMEONE** monorepo.

## Project Structure

```text
HOMEONE/
├── homeone-backend/       # NestJS backend with Supabase PostgreSQL & Auth
└── ...                    # Frontend application (Expo / React Native / Web)
```

## Getting Started

### Backend
Navigate to `homeone-backend/` and follow the instructions in [homeone-backend/README.md](homeone-backend/README.md).

```bash
cd homeone-backend
npm install
cp .env.example .env
npm run start:dev
```
