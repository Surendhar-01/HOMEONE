# HOMEONE – All-in-One Home Services

Welcome to the **HOMEONE** repository.

## Project Structure

```text
HOMEONE/
├── homeone-backend/       # NestJS backend with Supabase PostgreSQL & Auth
└── my-react-app/          # React + Vite frontend application
```

## Getting Started

### 1. Backend
Navigate to `homeone-backend/` and follow the setup instructions in [homeone-backend/README.md](homeone-backend/README.md).

```bash
cd homeone-backend
npm install
cp .env.example .env
npm run start:dev
```

### 2. Frontend
Navigate to `my-react-app/` and run the development server:

```bash
cd my-react-app
npm install
npm run dev
```
